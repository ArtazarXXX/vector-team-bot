# 📦 Список библиотек и используемых зависимостей проекта «ВЕКТОР»

В данном документе приведен полный перечень библиотек, фреймворков, системных компонентов и их точных версий, используемых в чат-боте «ВЕКТОР» (для хакатона «Идея фикс», мессенджер MAX / Сферум).

Все версии зафиксированы в `package.json` и заморожены в `package-lock.json` для обеспечения 100% воспроизводимости сборки.

---

## 1. Основные runtime-зависимости (Production)

| Библиотека | Точная версия | Назначение / Обоснование использования | Лицензия |
| :--- | :---: | :--- | :---: |
| **`@maxhub/max-bot-api`** | `1.1.0` | Официальный SDK платформы мессенджера MAX (Сферум). Обеспечивает получение обновлений через Long Polling, отправку форматированных текстовых сообщений, вложений и работу с интерактивными Inline-клавиатурами (`InlineKeyboardMarkup`). | MIT |
| **`better-sqlite3`** | `13.0.3` | Быстрая, синхронная и надежная встраиваемая СУБД SQLite для Node.js. Используется для локального персистентного хранения верифицированных олимпиад, хакатонов, закладок пользователей и паспортов проектов. Настроена на работу в режиме WAL (Write-Ahead Logging). | MIT |
| **`openai`** | `4.104.0` | Официальный клиент OpenAI-совместимого API. Используется для интеграции с языковыми моделями (DeepSeek-Chat, Qwen 2.5) через шлюз OpenRouter для генерации проектных гипотез, паспортов проектов и вопросов симулятора защиты. | Apache-2.0 |
| **`fast-xml-parser`** | `5.12.0` | Высокопроизводительный бессерверный валидатор и парсер XML/RSS данных. Используется модулем автоматического мониторинга и парсинга открытых образовательных лент и агрегаторов конкурсов. | MIT |
| **`dotenv`** | `16.6.1` | Менеджер переменных окружения. Загружает параметры конфигурации (токены, URL платформы, таймауты) из файла `.env` в `process.env`. | BSD-2-Clause |

## 4. Проверка и аудит зависимостей

Для проверки целостности и установленных версий в терминале можно выполнить команду:
```bash
npm list --depth=0
```

Для проверки уязвимостей (Security Audit):
```bash
npm audit
```
